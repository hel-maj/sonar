# Ручной сбор данных вываживания

Инструмент пассивно читает память `GTA5.exe` и состояние клавиш `A` / `D`.
Он не нажимает клавиши и не запускает бота.

## Один прогон

1. Запустите игру и подготовьтесь к ручному вываживанию.
2. Из PowerShell в корне `02_sonar_app` выполните:

```powershell
.\scripts\record_manual_reeling.ps1 -Label pier_north_camera_left
```

3. Дождитесь сообщения `Recording starts in 5...`: первичное разрешение адресов памяти выполняется до полезного окна записи.
   После этого есть 5 секунд, чтобы переключиться в игру.
4. Вываживайте рыбу вручную и нажимайте только правильную для текущего
   положения рыбы клавишу `A` или `D`.
5. После завершения вываживания перестаньте нажимать `A` / `D`. Инструмент сохранит
   ещё 5 секунд хвоста для анализа состояния «рыба поймана» и завершит запись сам.
   Максимальная длительность записи — 30 секунд.

Для другого времени записи:

```powershell
.\scripts\record_manual_reeling.ps1 -Label lake_south_camera_right -Duration 90
```

Автоостановку можно отключить, передав `-AutoStopIdle 0`.

Для каждого места и ракурса используйте отдельную понятную метку.

## Результаты

Файлы записываются в `logs\reeling_direction_probes`:

- `*.npz` — полный слепок для анализа;
- `*.jsonl` — читаемая временная шкала;
- `*.report.txt` — сравнение текущих direction-полей с ручными `A` / `D`;
- `*.analysis.txt` — поиск коррелирующих полей в широких слепках памяти;
- `*.completion.txt` — кандидаты memory-признака завершённого вываживания;
- `*.fixture.npz` — компактный кандидат для regression-теста.

После анализа подтверждённые `*.fixture.npz` копируются в
`tests\fixtures\reeling_direction`.

## Независимая разметка направления

Если нужно отделить визуальное направление рыбы от реакции памяти на управление,
запускайте запись с независимыми метками:

```powershell
.\scripts\record_manual_reeling.ps1 -Label visual_no_input_01 -LabelKeys Arrows -Duration 30
```

Во время записи не нажимайте `A` / `D`. Удерживайте `Left` или `Right` как метку
требуемой кнопки вытягивания: против видимого направления рыбы. Рыба может сорваться: для анализа
достаточно короткого участка. Реальные состояния `A` / `D` сохраняются отдельно
от стрелок и позволяют проверить, что метки не смешались с управлением.
