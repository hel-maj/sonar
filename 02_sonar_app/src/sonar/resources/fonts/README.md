# Inter

Этот каталог содержит статические TTF-файлы Inter 4.1 для интерфейса Sonar Fishing.

- Источник: официальный релиз [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1), архив `Inter-4.1.zip`.
- SHA-256 исходного архива: `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`.
- Лицензия: SIL Open Font License 1.1, полный текст находится в `LICENSE.txt`.
- Включенные начертания: обычное и курсивное для весов 400, 500, 600, 700 и 800.
- Контрольные суммы файлов: `SHA256SUMS`.

Приложение загружает TTF/OTF из этого каталога через Qt при старте. Семейство `Inter` выбирается первым, затем используются системные `Segoe UI Variable`, `Segoe UI` и `Arial`.
